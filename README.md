## 几个常被问到的点

**Pro 和 EB 哪个更快？** 没有统一答案，取决于你的宽带。电信用户走 Pro 的 CN2 GIA 回程通常最稳；联通和移动用户用 EB 的 AS9929 / CMIN2 往往不输，甚至更好。先测再买，别按价格猜。

**T1.WEE 那么便宜，能当主力站吗？** 技术上能跑，但 T1 不含中国方向优化，大陆访客的体验会比 Pro、EB 差一档。它更适合做备份机、探针、中转节点这些不在乎回国延迟的活。

**1GB 内存够吗？** 跑一个纯静态站或者单挂一个轻量代理够。跑 WordPress 加几个插件、再开个数据库和 Redis，1GB 会很紧张。这是 T1 和 Pro 入门的实际分水岭，不是纸面参数问题。

**库存多久补一次？** 没有固定节奏。AS3 这三条线在最近一年里有过多轮补货，Pro、EB、T1 组合齐上也有过。看到有货就下手通常比等下一轮稳妥，尤其是年付特价机。
